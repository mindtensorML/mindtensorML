# Caesar Rana, CFA, APMG CP3P

I map how investment work actually gets done, step by step. Every task gets an owner, a citation to the published standard that speaks to it, and a tag for what a model can run, what it drafts for sign-off, and what stays with people. Then the map is written as a skills file an AI agent can follow.

I built these maps at SpaceXAI, where I lead the portfolio management pod. Each was revised in October 2026 against a published standard and independently checked. Together they cover more than 600 mapped tasks. The first version of the EM infrastructure portfolio map was turned into a skills file that a frontier model followed through most of the process. That design is now the basis of an ongoing SpaceXAI project.
