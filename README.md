# Caesar Rana, CFA

I map how investment work actually gets done, step by step. For each step I decide whether a model can do it alone, whether a person should review it, or whether it has to stay with people. Then I write the map as a skills file an AI agent can follow.

These maps were built at SpaceXAI, where I lead the portfolio management pod, and are shared with permission. Together they cover more than 500 mapped steps and tasks. One of them, the EM infrastructure portfolio process, was turned into a skills file that a frontier model followed through most of the process. That design is now the basis of an ongoing SpaceXAI project.
